Items flagged for review before production. **Nothing has been removed yet.** Review each section and confirm what to keep, move, or delete.

## Category A: Likely Safe to Remove

These files appear to be duplicates, generated artifacts, or one-time-use items that no longer serve a purpose.

### A1. `package-lock.json` (root)

**Issue:** Project uses Bun (`bun.lock`). Having both lock files can cause confusion or install drift if `npm install` is accidentally run.
**Recommendation:** Delete `package-lock.json`. Commit `bun.lock` only.

### A2. `tsconfig.tsbuildinfo` (root)

**Issue:** This is a TypeScript incremental build cache file. Should be gitignored, not committed.
**Recommendation:** Add to `.gitignore`, delete the file.

### A3. `fonts/pangram-sans 2/` (duplicate font folder)

**Issue:** A second copy of the PP Pangram Sans fonts exists in `fonts/pangram-sans 2/`. The app reads from `fonts/pangram-sans/` only (configured in `app/layout.tsx`).
**Recommendation:** Confirm `fonts/pangram-sans 2/` is unused, then delete it.

### A4. `yield-*.svg` files at project root

**Issue:** Four SVG files (`yield-vh.svg`, `yield-h.svg`, `yield-m.svg`, `yield-l.svg`) sit at the project root. Static assets should live in `public/` to be served at runtime.
**What to check:** Are these referenced anywhere in code? If unused, delete. If used, move to `public/images/ui/`.

### A5. `temp/` directory

**Issue:** Contains processing reports (`processing-report.json`, `failed-snakes.json`, `validation-report.json`) generated by image scripts. These are runtime artifacts, not source files.
**Recommendation:** Add `temp/` to `.gitignore`. Clear before deploy. Do not commit.
